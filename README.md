## 🌟 Overview & Key Features

This portfolio is an executive showcase designed specifically for **tech recruiters, hiring managers, and software engineering interviewers**. It combines a bold **Neo-Brutalist Light visual style** with real production project case studies, interactive 3D WebGL canvases, verified hackathon credentials, and downloadable PDF resume integration.

### ✨ Highlights & Differentiators:
- 💳 **Developer ID Badge & 3D Neural Canvas**: Interactive 2.5D vector polyhedral matrix built on HTML5 Canvas with smooth mouse inertia damping.
- 💼 **Recruiter Snapshot Section**: Direct breakdown of target roles (*AI/ML Engineer, Full-Stack Developer, Python Backend SDE*), location mobility (*Kolhapur / Open to Remote & Relocation*), and instant interview booking.
- 🚀 **5 Flagship Systems & Case Studies**: Deep-dive modals for **OmniMind AI** (Multi-Agent ERP), **Saffron** (Restaurant POS), **Agentrix** (AI Voice Platform), **MediCare** (Hospital OS), and **Nexus OS** (3D WebGL Spatial App).
- 🏆 **6 Global & National Hackathons Grid**: Complete track of competitions including **NASA International Space Apps Challenge** (*Galactic Problem Solver*) and **Smart India Hackathon (SIH 2025)** (*National Participant*).
- 📜 **Verified Certificate Gallery**: Modal document viewer for official credentials from NASA, Ministry of Education & AICTE, OpenAI Academy, and NIAT.
- 🏗️ **System Architecture Lab**: Engineering design case studies showing data flows, decoupled architecture patterns, and measurable results.
- 📄 **1-Page PDF Resume Download**: Dynamic generation of job-ready resume PDF with embedded metadata (`Om_Khade_Resume.pdf`).

## ⚡ Local Setup & Development Quickstart

Follow these steps to run the portfolio locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/khade8915-lgtm/portfolio.git

# 2. Navigate into the project folder
cd portfolio

# 3. Install npm dependencies
npm install

# 4. Start Vite local development server
npm run dev
```

Open your browser and navigate to **`http://localhost:5173/`**.

### 🔨 Production Build Test
To test the production build locally:

```bash
npm run build
npm run preview
```

## ☁️ Render.com Deployment Guide

To deploy this portfolio to **Render.com**:

1. Log into [Render Dashboard](https://dashboard.render.com/) and create a **New Static Site**.
2. Connect this repository: `khade8915-lgtm/portfolio`.
3. Fill in the following build options:
   - **Build Command**: `npm run build`
   - **Publish Directory**: `dist`
4. Under **Settings → Redirects/Rewrites**, add the Single Page Application (SPA) rule:
   - **Source**: `/*`
   - **Destination**: `/index.html`
   - **Action**: `Rewrite`
